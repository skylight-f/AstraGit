# 标题栏拖动与底部溢出修复

## 原因与修改

右上角评审入口的父容器占据标题栏右侧整列，却整列设置了 `no-drag`，使空白区域也不能拖动窗口。改为容器 `drag`、实际按钮 `no-drag`，搜索框保持原来的交互区域。

内容区底部常驻横向滚动条来自共用分隔条的 `::before { inset: -3px }`。水平分隔条虽然只有 6px 高，热区却越过左右端点各 3px，使历史布局和外层卡片都产生 3px 横向溢出。现在仅沿调节方向扩展热区：左右分隔条 `inset: 0 -3px`，上下分隔条 `inset: -3px 0`。保留易于命中的热区，不修改代码区和提交列表的正常滚动。

## 验证

- 使用真实 `pnpm dev` 与隔离数据，建立 core/web 两仓库项目，包含长中文分支、长提交说明和长代码行。CSS 保存后直接热更新。
- 同一窄内容区测量：修复前外层卡片 `clientWidth=507 / scrollWidth=510`，修复后两者均为 `507`；历史布局与分隔条亦无额外横向宽度。未隐藏系统滚动条。
- 选中提交后的差异中，代码面板 `clientWidth=139 / scrollWidth=3027 / overflow-x=auto`，仍可独立滚动；外层卡片保持 `507 / 507`。
- 真实界面检查历史空态、选中提交、文件状态、项目提交以及评审侧栏；评审按钮可正常打开与关闭，历史分隔条键盘调节可更新百分比。
- 右侧标题栏计算样式为 `drag`，评审按钮为 `no-drag`。原生工具拖动未确认到窗口位移，保留人工手势补验，不把样式检查作为窗口实际位移的证明。
- `pnpm check:lockfile`、全仓 `pnpm lint`、Renderer 生产构建及 `git diff --check` 通过。没有增加依赖；未正式打包、推送或发布。

隔离数据和开发日志：`.tmp/window-layout-20261103-IK8UWq/`。
