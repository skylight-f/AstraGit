# AstraGit 独立图标与启动一致性

> **2026-10-16 更正**：本记录的系统图标 API 摘要比较不能证明实际 Dock 外观一致。用户反馈仅保留 ICNS 会使 Dock 带圆角底板且缩小；现已恢复与 Astra 相同的透明 PNG 运行图标。最新实现与验证范围见 [推送行距与透明 Dock 修复](推送行距与透明Dock修复-2026-10-16.md)。

## 问题与证据

用户反馈应用未打开和打开时图标不一致，并要求与 Astra 同风格、构图独立。

- 已安装 v0.1.7 的 `icon.icns`、`branding/icon.png` 分别与当时源码产物摘要相同，文件内容没有版本漂移。
- 启动前图标由应用包的 `CFBundleIconFile` 提供；原 Main 在启动后调用 `app.dock.setIcon` 改为透明 PNG。Finder 的系统图标预览带圆角底板，两条展示路径会造成外观差异。Electron 的 [Dock API](https://www.electronjs.org/docs/latest/api/dock#dockseticonimage-macos) 明确该调用会替换 Dock 图像。
- 开发资源监听虽然触发 Main 重启，旧控制脚本却只在最初启动时准备运行环境；ICNS 缓存不能随资源变更更新。

## 实现

1. 用户进一步明确参考为 JetBrains 风格，因此采用黑色方块、白色 AG 字标、底部短横线和彩色几何叠片。叠片角度和轮廓独立于 Astra，不采用此前被否定的菱形分支节点方案。AG 已转为固定 SVG 路径，不依赖运行时字体。
2. macOS 使用系统应用包 ICNS，移除启动后的 Dock PNG 替换；页面 Logo 与 favicon 沿用同一 SVG 设计源。
3. 开发实例正常退出后调用带摘要缓存的 `developmentRuntime`，仅在资源变化时重建并重新签名独立运行环境。
4. 新增 `check:icons`：检查设计源 / 生成脚本 / PNG / ICNS 摘要、RGBA 1024px 尺寸、全部 10 档图层及最高分辨率图像一致性。iconutil 会修改 EXIF，因此图像比较使用颜色描述和解压后的 PNG 数据。
5. 完整发布门禁及 `build:app` / `build:release` 接入图标检查；打包后额外校验实际 ICNS 与源码一致。

## 验收

- `pnpm verify:publish` 通过：锁文件、隔离、图标、lint、类型、31/31 项测试、全部包生产构建。
- 干净临时目录 `pnpm install --frozen-lockfile --offline` 安装 413 项依赖通过；图标检查通过。故意只改临时副本 SVG 后，一致性门禁正确拒绝，临时目录随后清理。
- `pnpm build:app` 构建 arm64 `release/mac-arm64/AstraGit.app`，版本 0.1.8，身份 `com.astragit.desktop`；ASAR、PNG、ICNS 和 ad-hoc 签名校验通过，未生成 DMG。
- 用全新 `.tmp/icon-brand-review/jetbrains-data` 启动最终 AG 正式包，Renderer 报告就绪；真实界面项目列表显示新 Logo，系统包图标显示 AG 字标和独立叠片。
- 通过 macOS AppKit 读取最终包启动前的系统图标与 PID 53837 的运行图标，256px PNG 的 SHA-256 均为 `8e75979f3f1eb17de936e324b4ed6ff9f059c6f4c20879a1791ea41833b55956`，按字节比较完全一致。
- 最终截图与图标快照：`.tmp/acceptance/icon-jetbrains-preview.png`、`icon-jetbrains-formal-app.png`、`icon-jetbrains-system-closed.png`、`icon-jetbrains-system-running.png`。此前菱形提案的旧快照保留作过程记录，不作为最终图标验收。
- 优先启动了真实 `pnpm dev`，编译与资源更新触发重启；中途因原生退出等待钥匙串导致旧开发窗口读取超时。系统返回 `userCanceledErr` 后控制脚本自动重新编译并启动 PID 6763，真实开发工作台界面复查通过，快照为 `.tmp/acceptance/icon-development-recovered.png`。开发重启仍可能受原生钥匙串等待影响。
- 此前菱形提案的临时正式实例请求退出后服务已关闭，但原生线程等待钥匙串，采样确认后清理了该隔离实例。最终 AG 实例在系统返回 `userCanceledErr` 后正常退出，进程返回码 0；此次不包含钥匙串问题已修复的结论。

本轮未提交、推送、发布或覆盖 `/Applications/AstraGit.app`，未使用正式用户数据。
