# 加载状态下拉箭头修复

## 现象与原因

推送、AI 生成等忙碌期间，原生 select 出现整排重复下拉箭头。多处表单的局部 background 简写重置 background-repeat、background-position 和 background-size；styles.css 的 select:disabled 又以更高优先级只恢复 background-image，最终按默认 repeat 平铺 SVG。fieldset 禁用也会使其中 select 匹配 :disabled，因此问题集中在加载时出现。

## 修复

修改共享 styles.css 的原生下拉禁用规则，完整声明：

- 右侧 13px、垂直居中。
- background-repeat: no-repeat。
- background-size: 12px 12px。
- 右侧 32px 文本留白。
- 同时覆盖 select:disabled 和 select[aria-disabled=true]；保持禁用底色与原行为。

没有更改 Git、AI 请求或选择器组件逻辑，也未逐页面叠加覆盖补丁。
