# 分支切换只在修改阻止切换时提示

日期：2026-10-24；当前分支：main。正式包验收已通过，已发布 v0.1.16。

## 现象与原因

仓库管理切换到其他分支时，即使工作区干净也显示“确认分支切换”。`ProjectGitWorkbench.execute` 对普通 checkout 的条件仅判断目标分支与当前分支不同；其余检出动作按文件状态数量提示。两种条件都没有判断本地修改是否真的阻止切换，造成无必要的确认。

## 修正行为

- 移除通用 `GitCheckoutDialog` 及等待确认的状态，沿用原 Git 执行与错误恢复链路。
- 工作区干净时直接切换；有兼容修改时直接切换并保留原修改，不自动贮藏。
- 会覆盖已跟踪修改或未跟踪文件时，Git 拒绝切换，现有诊断显示受影响文件、已确认的未切换/未覆盖事实，并提供查看文件、贮藏入口。
- 不使用强制检出，不丢弃修改，不在后台自动贮藏。已有冲突、未完成整合和其他错误继续由原分类处理。
