# AstraGit 正式构建与发行验收（2026-10-14）

## 实现范围

- 独立应用 `com.astragit.desktop`，六个自有 `@astragit/*` 包，用户数据与 Zeus 隔离。
- 顶部 `Git 工作台 / 源码更改` 实际切换；源码更改只汇总当前项目目录内的仓库。
- 仓库、目录、文件勾选；完整工作区版本或勾选文件的暂存版本；共享或逐仓库草稿、按范围 AI 填写。
- 逐仓库提交预览、分支/HEAD/内容指纹校验、临时索引保护、hook 范围保护、独立批次结果和失败 push 重试。
- 显式子模块引用更新与依赖执行；普通嵌套仓库保持独立。
- main 自动发行候选、双架构 DMG、更新清单；应用内检查、下载与签名条件下重启安装及失败恢复。

## 本地门禁

`pnpm verify:publish`：隔离检查、lint、typecheck、14 项回归、完整源码构建全部通过。

实际 Git 回归覆盖：两种勾选提交模式、未勾选索引保留、工作区后续修改保留、过期指纹、失败 hook 和扩大范围的 hook 阻断、当前项目多仓库发现、跨项目范围拒绝、子模块先提交及父引用、独立仓库并行结果、失败推送仅重试 push。更新回归覆盖版本占用、应用/下载来源/摘要校验、缓存复验及损坏下载清理。
