# 顶部搜索与快速定位

## 交互

顶部标题栏居中提供搜索框，支持 Cmd+K / Ctrl+K 唤起、上下方向键选择、回车定位、Esc 或点击外侧关闭。macOS 使用 hiddenInset 标题栏与原生红黄绿窗口按钮，搜索区域排除窗口拖拽，其余标题栏保留拖动区域。

搜索范围是已添加项目，以及当前项目的真实仓库和变更文件；不搜索未变更文件正文。项目按名称或目录匹配，仓库按名称、相对路径或分支匹配，文件支持路径、中文、多关键词与重命名前路径。文件结果区分已暂存和未暂存版本，同名文件按仓库独立定位。结果最多显示 40 条，空输入仅显示项目与仓库。

选择项目打开工作台；选择仓库切换对应仓库；选择变更文件打开对应暂存版本的差异。在项目提交视图搜索文件时切到仓库管理进行预览。定位只消费一次，之后返回项目或刷新不会重复定位。已过期的项目、仓库、文件或暂存版本会被拒绝。

Git 状态读取复用既有共享请求与缓存，只在展开搜索时刷新，输入文字不会逐字发起请求。跨项目或关闭后的异步结果不写入当前搜索状态；存在模态弹窗时快捷键不穿透。多仓库批次或仓库创建期间搜索暂时禁用。
