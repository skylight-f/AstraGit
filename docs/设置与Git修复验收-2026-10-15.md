## 已安装版问题定位

只读检查应用自己的操作记录，未在用户业务仓库执行提交或切换：

| 现象 | 实际原因 | 修复或交互 |
| --- | --- | --- |
| 设置里没有中英文切换 | 只有模型设置，未接入通用设置和语言偏好 | 统一设置 → 通用 → 界面语言，支持跟随系统 / 简体中文 / English |
| 提交失败 | Finder 启动 PATH 缺少 pnpm，Husky pre-commit 返回 127 | 启动服务前读取登录 shell 工具路径，保持 hooks 启用 |
| 新建分支失败 | 输入的分支名包含空格 | 输入时提示非法语法并禁用创建，合法中文分支可创建 |
| 切换分支被阻止 | 目标分支会覆盖本地未提交修改 | 保留 Git 保护，明确提示并可打开贮藏；不强制切换 |
| 操作状态和错误弹窗不准确 | 预检已执行只读命令却标成可能写入；同一错误重复订阅 | 已知未写入错误记为 failed_before_write，移除重复弹窗 |
