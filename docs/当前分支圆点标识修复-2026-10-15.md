# 当前分支圆点标识修复

## 问题与调整

分支导航此前在实际检出分支的右侧显示对勾。根据交互要求改成分支名称前的紫色圆点，移除对勾，保留当前分支加粗以及单击查看历史、双击切换分支的行为。

- `GitRepositoryControls.tsx`：在名称前渲染实际检出分支的圆点，可访问名称保留「当前检出分支」说明。
- `gitWorkspace.css`：圆点固定为 6px，利用现有缩进留白保持同层名称对齐。规则优先级覆盖导航中对所有 span 设置的 `flex: 1`，防止圆点被拉成长椭圆。
- 标记依据 `current`，查看历史的 `selected` 不改变检出标记；远程分支和标签不显示该圆点。

## 验证

- 使用 `pnpm dev` 和 `.tmp/ai-multi-review-20261015/data` 隔离数据运行真实 Electron 应用，CSS 修改通过热更新生效。
- 临时仓库的 `main` 与 `feature/当前分支圆点` 均显示名称前圆点，同层名称对齐、右侧无对勾。
- 双击临时分支后圆点跟随实际检出分支；单击 `feature/其他分支` 查看历史时，圆点仍保留在已检出分支上。
- `pnpm check:lockfile`、`pnpm lint`、`pnpm typecheck` 和 `git diff --check` 通过。
- 验收截图：`.tmp/acceptance/current-branch-dot-root.png`、`current-branch-dot-grouped.png`、`current-branch-dot-history.png`。

本轮仅本地界面修复，未提交、推送或发布。
