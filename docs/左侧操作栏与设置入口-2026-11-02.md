# 左侧操作栏与设置入口

## 交互与范围

应用使用 52px 固定宽度的左侧操作栏，顶部提供项目列表入口，设置齿轮固定在左下角。项目列表、仓库管理和项目提交共用同一操作栏；顶部项目页签与原视图下拉继续使用现有逻辑。移除工作台右上角及项目列表标题区重复的设置按钮，检测到更新时的顶部更新按钮继续保留。

设置沿用既有弹窗，包含通用语言、AI 模型及应用更新。操作栏提供中英文名称、悬停提示、键盘焦点样式与弹窗展开状态；Esc 关闭设置后焦点返回左下角齿轮。多仓库提交批次运行时，项目列表入口沿用现有禁止切走的约束。

布局、图标和交互仅修改 `apps/desktop/src/renderer/App.tsx`、`apps/desktop/src/renderer/app.css`，没有增加依赖或修改更新执行逻辑。
