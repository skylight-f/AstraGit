# 推送行距与透明 Dock 修复

## 问题与根因

1. 推送分支表格对每个单元格设置上下各 8px 留白，再叠加输入框高度，普通行约 46px，五条分支占用过多空间。
2. 上一轮为了让系统图标 API 的返回值在启动前后相同，移除了 `app.dock.setIcon`。实际结果是在运行中的 Dock 保留了系统给 ICNS 添加的圆角底板，图形也缩小，与 Astra 的透明几何外观不同。用户截图确认了该回退错误。
3. `NSWorkspace.icon(forFile:)` 与 `NSRunningApplication.icon` 返回相同图像，不代表 Dock 当前正在显示同一图像。本轮恢复 PNG 后，该系统查询仍返回带底板的包图标，因此不再使用此前哈希比较宣称 Dock 视觉一致。

## 修复

- `styles.css`：分支表格单元格上下各 2px 留白，远程分支输入框固定 28px，普通行约 32px；单元格垂直居中，表头保留 6px 留白。长名称仍可换行。
- `main.ts`：对照本机 Astra/Zeus 当前 `applyApplicationDockIcon`，开发和正式运行均使用同源透明 PNG 调用 `app.dock.setIcon`。图标缺失或 Dock 不可访问时明确报错。
- 保留已经确认的 JetBrains 风格 AG 字标与独立几何叠片，不重画 SVG，也不修改资源生成和发布逻辑。
- Finder 与未运行状态仍使用同源 ICNS，由 macOS 处理系统外观；本轮不把此状态误报为已实现与透明 Dock 完全相同。
