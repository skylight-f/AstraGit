## 安装与更新

Homebrew 安装：`brew install --cask skylight-f/tap/astragit`；升级：`brew upgrade --cask skylight-f/tap/astragit`。应用内「应用更新」会识别 Homebrew 安装，校验下载后通过 brew 升级并重启；Homebrew 通道不要求应用自替换的 Developer ID 条件。

也可下载与 Mac 架构匹配的 DMG。DMG 通道的自动重启安装要求当前应用及新版使用同一 Developer ID 团队，且新版通过 Apple 公证；条件不足时可校验下载并手动安装。两种方式均保留 macOS 安全检查。

项目、模型配置、草稿和用户数据独立存储于 AstraGit，不与 Zeus 共用。
