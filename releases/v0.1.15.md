# AstraGit 0.1.15

## 更新内容

- 补齐仓库克隆、初始化、仓库身份与远程设置、分支和上游关系管理。
- 改善分支切换失败提示，区分本地修改覆盖、未跟踪文件覆盖及已有冲突，并提供明确处理入口。
- 补齐合并、变基、拣选和反向提交的恢复流程；冲突暂停后直接显示右侧编辑器，支持继续、终止和适用场景下的跳过。
- 增加提交修订与 Git 提交模板，保留手工和 AI 草稿；多仓库说明分别使用自己的模板。
- 完善历史搜索、文件历史、代码归属、双提交总差异、合并父级比较、逐行和区块操作。
- 补齐标签、忽略与停止跟踪、补丁、源码存档、子模块、外部比较工具、LFS 和内置 Git Flow。
- 修复嵌套错误弹窗返回后无法操作、浮动提示遮挡提交按钮及推送旧回执残留。
- 保留 AI 提交、项目内多仓库提交、双视图、项目标签拖拽和可调分栏。

## 安装与更新

安装：`brew install --cask skylight-f/tap/astragit`

升级：`brew upgrade --cask skylight-f/tap/astragit`

Homebrew 安装版可在设置中检查更新；后台升级使用上述 Homebrew 命令，完成后点击重启启用新版。项目、模型配置与提交草稿保留。

也可从本发行下载对应 Mac 架构的 DMG。安装包的签名与公证状态以发行清单为准，保留 macOS 系统安全检查。
