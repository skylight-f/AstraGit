本版本包含 main 分支中通过检查的改动。[查看源码提交](https://github.com/skylight-f/AstraGit/commit/8f6501ecd4a02062b50ec9d80c9e12b82ffc4b73)。

## 下载安装

- [Windows x64 安装包（EXE）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.27/AstraGit-0.1.27-win-x64-setup.exe)。请先安装 Git for Windows，并将 Git 加入 PATH。更新时下载并运行新版安装包。
- [macOS Apple Silicon（DMG）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.27/AstraGit-0.1.27-arm64.dmg)
- [macOS Intel（DMG）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.27/AstraGit-0.1.27-x64.dmg)

macOS 也可运行 `brew install --cask skylight-f/tap/astragit` 安装，或运行 `brew upgrade --cask skylight-f/tap/astragit` 升级。应用内「应用更新」会识别 Homebrew 安装，校验下载后通过 brew 升级并重启。

DMG 通道的自动重启安装要求当前应用及新版使用同一 Developer ID 团队，且新版通过 Apple 公证。条件不足时，可校验下载并手动安装。
