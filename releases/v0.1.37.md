# AstraGit 0.1.37

## 更新内容

- 优化项目列表与 Git 工作台交互 - 新增项目分组管理，并支持按组整理项目 - 抽离提交历史表格，支持调整并保存列宽 - 在推送和拉取对话框中展示操作状态并支持中止 - 优化提交文件列表、差异颜色及同步表格滚动布局
- 统一项目导航状态并优化文件列表交互

[查看完整变更](https://github.com/skylight-f/AstraGit/compare/v0.1.36...22968c38fcdb368c17386a7f4d3ac27480e2902a)。

## 下载安装

- [Windows x64 安装包（EXE）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.37/AstraGit-0.1.37-win-x64-setup.exe)。请先安装 Git for Windows，并将 Git 加入 PATH。支持自动更新的版本会在后台下载并校验新版，就绪后可在「应用更新」选择「重启并更新」。仅支持手动更新的旧版可下载并运行此安装包。
- [macOS Apple Silicon（DMG）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.37/AstraGit-0.1.37-arm64.dmg)
- [macOS Intel（DMG）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.37/AstraGit-0.1.37-x64.dmg)

macOS 也可运行 `brew install --cask skylight-f/tap/astragit` 安装，或运行 `brew upgrade --cask skylight-f/tap/astragit` 升级。应用内「应用更新」会识别 Homebrew 安装，校验下载后通过 brew 升级并重启。

DMG 通道的自动重启安装要求当前应用及新版使用同一 Developer ID 团队，且新版通过 Apple 公证。条件不足时，可校验下载并手动安装。
