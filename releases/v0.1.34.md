## 下载安装

- [Windows x64 安装包（EXE）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.34/AstraGit-0.1.34-win-x64-setup.exe)。请先安装 Git for Windows，并将 Git 加入 PATH。支持自动更新的版本会在后台下载并校验新版，就绪后可在「应用更新」选择「重启并更新」。仅支持手动更新的旧版可下载并运行此安装包。
- [macOS Apple Silicon（DMG）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.34/AstraGit-0.1.34-arm64.dmg)
- [macOS Intel（DMG）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.34/AstraGit-0.1.34-x64.dmg)

macOS 也可运行 `brew install --cask skylight-f/tap/astragit` 安装，或运行 `brew upgrade --cask skylight-f/tap/astragit` 升级。应用内「应用更新」会识别 Homebrew 安装，校验下载后通过 brew 升级并重启。

DMG 通道的自动重启安装要求当前应用及新版使用同一 Developer ID 团队，且新版通过 Apple 公证。条件不足时，可校验下载并手动安装。
