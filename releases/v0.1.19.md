# AstraGit 0.1.19

## 更新内容

- 新增左侧操作栏，项目列表与设置入口集中到左侧。
- 新增顶部搜索，支持搜索项目、当前项目的仓库和变更文件，使用 ⌘/Ctrl K 快速定位。
- 新增右侧代码评审：选择当前项目全部仓库或单个仓库，分析工作区或已暂存改动，展示修改影响、潜在问题、修复建议及建议验证项。
- 评审复用现有 AI 模型配置，支持取消、面板宽度调整、问题文件定位，以及代码变化后的报告过期提醒。
- 精简项目标签栏，移除常驻的本地目录路径。
- 修复 Safe Storage 反复授权：按用户选择对齐 Astra/Zeus 的 macOS 浏览器存储策略，升级 Electron、隔离验收身份，并合并 AI 密钥的重复读取。AI API 密钥继续使用独立系统钥匙串；浏览器 Cookie 不再使用系统钥匙串加密。

代码评审基于提供给模型的差异，只读分析，不自动修改代码或运行测试。大文件、生成文件、二进制及子模块引用等评审限制会在报告中说明。

## 安装与更新

Homebrew 安装：`brew install --cask skylight-f/tap/astragit`。

Homebrew 升级：`brew upgrade --cask skylight-f/tap/astragit`。应用内在左下角设置的「应用更新」中检查；检测到更新后，顶部会出现更新入口，准备完成后可重启升级。

也可下载适合 Mac 架构的 DMG。未公证的包仍遵循 macOS 系统安全检查；DMG 通道的应用内自动替换需满足 Developer ID 签名与公证要求。

项目、模型配置和草稿独立存储在 AstraGit，不与 Zeus 共用。
