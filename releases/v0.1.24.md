# AstraGit 0.1.24

## 更新内容

- 项目提交将文件按仓库展示，统一项目提交和暂存视图的 AI 模型选择。模型设置可从下拉菜单打开。
- 贮藏差异可在右侧直接预览。右键菜单支持应用、应用并移除、复制引用与删除，执行前会核对目标贮藏。
- 改进冲突编辑时的状态刷新、暂存前的冲突标记检查和首次推送时的目标分支选择。
- 修复重复写入已有数据库迁移记录导致的启动问题，并在启动失败时显示原因。
- 发布时核对 arm64 和 x64 安装包及更新清单，并同步 Homebrew Cask。

## 安装与更新

通过应用内的「应用更新」检查新版。Homebrew 用户也可以运行 `brew upgrade --cask skylight-f/tap/astragit`，或在 GitHub Release 下载与 Mac 架构匹配的 DMG。
