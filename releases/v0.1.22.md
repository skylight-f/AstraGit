# AstraGit 0.1.22

## 更新内容

- 修复 macOS 系统代理下 SSH 连接将成功的 CONNECT 响应误判为失败的问题，兼容原生 nc 的 HTTP/1.0 握手，保持隧道内数据原样传输。
- 分别提示 SSH 代理协议不兼容、代理拒绝、连接断开及 Git HTTP 502，保留原始诊断和操作结果核对提示。
- 修复标题栏右侧空白区域无法拖动窗口的问题，调整项目管理操作按钮及页面底部布局。

本次更新保留系统代理路由、SSH 主机身份校验和用户配置，不自动重试 Git 写操作。如果网络仍会断开 GitHub 的 22 端口连接，需要单独处理代理规则；此更新不会自动修改 SSH 端口或远端地址。

## 安装与更新

Homebrew 安装：`brew install --cask skylight-f/tap/astragit`；升级：`brew upgrade --cask skylight-f/tap/astragit`。也可在应用的“应用更新”中检查新版，或下载与 Mac 架构匹配的 DMG。

DMG 通道的自动重启安装要求当前应用及新版使用同一 Developer ID 团队，且新版通过 Apple 公证；条件不足时可校验下载并手动安装。两种方式均保留 macOS 安全检查。

更新保留 AstraGit 的项目、模型配置、草稿和用户数据。
