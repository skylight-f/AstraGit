# AstraGit 0.1.5

## 更新内容

- 新增统一设置，支持跟随系统、简体中文和 English，切换立即生效并记住选择。
- 修复 Finder 启动后 Git hooks 找不到 pnpm、Node 等工具而导致的提交失败，保持 hooks 正常执行。
- 新建分支时提前提示空格等非法字符，保留中文分支支持；切换可能覆盖本地修改时提示贮藏入口，修复重复报错及操作状态误判。
- 模型连接支持编辑名称、API 地址和目录路径，保留已配置密钥和模型选择；普通模型使用桌面系统网络栈。
- 完善项目、操作历史与回退凭据的持久化和错误恢复，增加同一数据目录单实例保护。
- 完善开发热更新：Renderer Fast Refresh，Main/preload/本地包编译成功后自动重启；开发数据和身份独立。

原 Git 工作台和当前项目内多仓库的源码更改视图继续共存。

## 安装与更新

Homebrew 安装：`brew install --cask skylight-f/tap/astragit`。

已有安装：窗口右上角 **应用更新 / App updates → 检查更新 / Check for updates → 下载更新 → 通过 Homebrew 升级并重启**。也可运行 `brew upgrade --cask skylight-f/tap/astragit`。

应用核对安装渠道、下载大小和 SHA-256，再通过 Homebrew 管理升级并保留项目、模型配置及草稿。macOS 系统安全检查保留；未公证安装包的系统提示需本人处理。

手动 DMG 安装需选择匹配 Mac 架构的安装包。DMG 自动替换要求当前应用和新版使用同一 Developer ID 团队且新版通过 Apple 公证；不满足时提供手动安装。
