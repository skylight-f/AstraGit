# AstraGit 0.1.0

## 更新内容

本版本包含 main 分支中通过检查的改动。[查看源码提交](https://github.com/skylight-f/AstraGit/commit/1568caae0b7c1c6649353f049f66bb19a910cb75)。

## 安装与更新

下载与 Mac 架构匹配的 DMG。应用内「应用更新」可以检查和下载更新；自动重启安装要求当前应用及新版使用同一 Developer ID 团队，且新版通过 Apple 公证。未配置签名、公证时需手动安装。

项目、模型配置、草稿和用户数据独立存储于 AstraGit，不与 Zeus 共用。
