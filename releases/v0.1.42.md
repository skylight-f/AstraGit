# AstraGit 0.1.42

## 更新内容

- 保留差异读取的错误码
- 保留工作台的索引损坏诊断
- 增强 Git 提交选项并新增原生菜单
- 优化 Git 推送界面并移除提交模板功能
- 增加 Git 工作台初始变更预览并优化快照缓存

[查看完整变更](https://github.com/skylight-f/AstraGit/compare/v0.1.41...0501cf995195d875e073bcf78d28b5ab44b02075)。

## 下载安装

- [Windows x64 安装包（EXE）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.42/AstraGit-0.1.42-win-x64-setup.exe)。请先安装 Git for Windows，并将 Git 加入 PATH。支持自动更新的版本会在后台下载并校验新版，就绪后可在「应用更新」选择「重启并更新」。仅支持手动更新的旧版可下载并运行此安装包。
- [macOS Apple Silicon（DMG）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.42/AstraGit-0.1.42-arm64.dmg)
- [macOS Intel（DMG）](https://github.com/skylight-f/AstraGit/releases/download/v0.1.42/AstraGit-0.1.42-x64.dmg)

macOS 也可运行 `brew install --cask skylight-f/tap/astragit` 安装，或运行 `brew upgrade --cask skylight-f/tap/astragit` 升级。应用内「应用更新」会识别 Homebrew 安装，校验下载后通过 brew 升级并重启。

DMG 通道的自动重启安装要求当前应用及新版使用同一 Developer ID 团队，且新版通过 Apple 公证。条件不足时，可校验下载并手动安装。
