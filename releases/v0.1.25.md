# AstraGit 0.1.25

## 更新内容

- 项目提交、暂存与未暂存和分支视图共用紧凑的 Git 工具栏。提交视图的切换按钮与 Git 操作分列同一行。
- 拖动项目标签时，用带项目名的蓝色虚线占位显示落点。提交确认弹窗的关闭、返回修改和确认按钮采用统一样式。
- 设置面板随窗口伸缩，可通过左侧菜单切换。AI 模型设置按供应商组织，支持连接测试、同步模型目录、编辑模型及克隆供应商配置。
- 接口协议可在供应商配置中下拉切换。保存后，该供应商的现有模型和后续添加的模型使用同一协议。

## 安装与更新

通过应用内的「应用更新」检查新版。Homebrew 用户可运行 `brew upgrade --cask skylight-f/tap/astragit`，也可从 GitHub Release 下载对应 Mac 架构的 DMG。
